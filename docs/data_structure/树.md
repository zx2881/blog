## 树

### 树的定义

> 在任意一颗非空树中：
>  1) 有且只有一个根（root）
>  2) 当n>1时，其余节点可分为m个互不相交的子树。

## 二叉树

###  定义

- 每个节点至多只有两棵子树（二叉树中不存在度大于2的节点）
- 二叉树有左右之分，次序不能颠倒

### 性质

#### 性质1

> 二叉树的第 $i$ 个层上至多有 $2^{i-1}$ 个节点 $(i\geq1)$ 

#### 性质2

> 深度为k的二叉树至多有 $2^k-1$ 个节点

**证明**：等比数列求和$$\sum_{i=1}^{k} 2^{n-1}=2^k-1$$ 
#### 性质3

设 
- **叶节点数**：$n_0$ 
- **度为2的节点数**：$n_2$ 
可得：
> $n_0=n_2+1$ 

证明过程：联立
> $$(1)n=n_0+n_1+n_2$$
> $$(2)n=n_1+2n_2+1$$

证明（2）：设B为分支总数
$$\begin {cases}
	B&=n_1+2n_2 \\
	n_0&=n_2+1
	\end {cases}$$

```C++
//核心函数：siftDown(下沉)
void SiftDown(Heap H,int pos){
	while(pos<=H->len/2){//循环结束条件：pos为叶
		int c=pos*2;
		int rc=pos*2+1;
		if (rc<=H->len&&!Prior(H->elem[c],H->elem[rc]))
			c=rc;
		if(H->prior(H->elem[pos],H->elem[c])) return;
		swapElem(H,pos,c);
		pos=c;
	}
}
```

## 树和森林

**树的存储：链表结构**

| 树的存储结构  | 特点          |
| ------- | ----------- |
| 双亲表示法   | 找父亲容易，找儿子麻烦 |
| 孩子表示法   | 找儿子容易，找父亲麻烦 |
| 双亲孩子表示法 | 额外存储开销      |
1. 双亲表示法
*存储表示：*

2. 孩子表示法
	**Q：每个节点孩子的数量不一定，怎么存？**
	**A：使用链表来存储孩子**

存储表示：
```C++

template <typename ElemType>
//节点数组内的孩子节点
struct CTNode{
	int child;//孩子节点的下标
	struct CTNode* next;//指向下一个孩子节点的指针
}
//树中真正存放数据的孩子节点
struct CTBox{
	ElemType data;
	CTNode* firstchild;//只存第一个孩子，后面的它自己会连接
}
//树
struct CTree{
	CTBox* nodes;//依旧堆分配内存；
	int n;//节点数
	int r;//根节点的位置（-1）
	int size;//总分配数组容量
}
```
